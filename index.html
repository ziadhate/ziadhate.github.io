ENGINEERING GRADUATION PROJECT · 2026/2027

Autonomous AI-Powered Hospital Delivery & Infection-Control Robot

Smarter Hospital Logistics. Safer Healthcare Environments.

Hospitals rely on continuous transportation of medications, medical supplies, laboratory samples, meals and essential equipment between departments and patient rooms. These repetitive logistics tasks consume valuable staff time and can increase unnecessary human contact.

Our project aims to develop an autonomous mobile robot designed to support hospital logistics through intelligent navigation, secure delivery compartments and infection-control-oriented workflows.

THE PROPOSED SOLUTION

The robot is designed to navigate indoor hospital-like environments, transport requested items and deliver them to designated destinations with minimal human intervention. Authorized personnel can interact with its delivery compartments through a secure access mechanism.

Autonomous Navigation Indoor mapping, localization and path planning using LiDAR and ROS 2.
Secure Delivery Dedicated compartments with RFID, QR or barcode-based access concepts.
Smart Perception Camera-based environmental perception and obstacle awareness.
Infection-Control Workflow Separated delivery compartments and cleaning-oriented operational procedures.
Human-Robot Interaction Display-based communication, voice interaction concepts and status feedback.
Embedded Control Real-time motor control, sensor integration and safety monitoring.

HOW IT WORKS

01 — Delivery Request

An authorized user requests transportation of an item to a designated destination.

02 — Secure Loading

The item is placed inside the assigned delivery compartment.

03 — Autonomous Navigation

The robot uses its mapping and navigation system to move through the environment.

04 — Destination Arrival

The robot reaches the assigned location and notifies the authorized recipient.

05 — Secure Delivery

The recipient accesses the assigned compartment using an authorized method.

TECHNOLOGY STACK

ROS 2 Nav2 SLAM LiDAR Computer Vision Raspberry Pi STM32 Embedded C RTOS CAN Bus Python Linux

PROJECT OBJECTIVES

• Reduce repetitive transportation workloads.
• Improve delivery organization and traceability.
• Support controlled item handling workflows.
• Reduce unnecessary movement and contact.
• Demonstrate practical integration of robotics, embedded systems and artificial intelligence.
